# Parkinson_Disease_Detection
Machine Learning-Based Speech Analysis for Early Detection of Parkinson's Disease
📊 Project Overview

This project explores the use of machine learning to identify patterns associated with Parkinson's disease using voice-related features. It uses a dataset containing vocal measurements to train and evaluate classification models.

The project includes data preprocessing, feature scaling, model training, and performance evaluation to investigate the potential of speech analysis for supporting early detection research.

🎯 Objectives
- Analyze voice-related features from the dataset.
- Perform data preprocessing and feature scaling.
- Train multiple machine learning classification models.
- Compare model performance using evaluation metrics.
- Visualize model performance using confusion matrices.
- Explore the potential of voice analysis for early detection research.

- Accuracy

- F1-Score

📈 Project Features
- Data Preprocessing
- Feature Scaling using MinMaxScaler

- Multiple Classification Models
- Hyperparameter Tuning using GridSearchCV
- Model Evaluation and Comparison
- Confusion Matrix Visualization

💡 Project Outcomes

This project investigates how machine learning algorithms can classify voice-related measurements and distinguish patterns associated with Parkinson's disease.

The results can be used to compare classification models and explore their potential for further research.
